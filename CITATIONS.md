# Citation guide

## Cite this skill

Use GitHub's **Cite this repository** control, which reads [`CITATION.cff`](CITATION.cff), or cite the repository directly:

> jackwzt. (2026). *EAM and SBI Modeling Skill* [Computer software]. https://github.com/jackwzt/eam-modeling-skill

If you archive a release with a DOI, cite the archived release and version instead of the moving `main` branch.

## Cite the methods and software actually used

Citing this repository does not replace citations for the statistical model, estimator, or software used in an analysis. A ready-to-import BibTeX collection is provided in [`CITATIONS.bib`](CITATIONS.bib).

- **EMC2 analyses:** cite Stevenson et al. (2026), [doi:10.3758/s13428-025-02869-y](https://doi.org/10.3758/s13428-025-02869-y), and record the EMC2 version or commit.
- **BayesFlow 2 workflows:** cite Kühmichel et al. (2026), [arXiv:2602.07098](https://arxiv.org/abs/2602.07098). The BayesFlow project also lists Radev et al. (2023), [doi:10.21105/joss.05702](https://doi.org/10.21105/joss.05702), for the legacy/software-workflow paper.
- **Superstats or neural superstatistics:** cite Schumacher et al. (2023), [doi:10.1038/s41598-023-40278-3](https://doi.org/10.1038/s41598-023-40278-3). For validation and comparison of non-stationary cognitive models, also cite Schumacher et al. (2025), [doi:10.1007/s42113-024-00218-4](https://doi.org/10.1007/s42113-024-00218-4).
- **Diffusion decision models:** cite an appropriate primary or review source for the exact model; the bibliography includes Ratcliff et al. (2016), [doi:10.1016/j.tics.2016.01.007](https://doi.org/10.1016/j.tics.2016.01.007).
- **Linear ballistic accumulation:** cite Brown and Heathcote (2008), [doi:10.1016/j.cogpsych.2007.12.002](https://doi.org/10.1016/j.cogpsych.2007.12.002).
- **Simulation-based calibration:** cite Talts et al. (2018), [arXiv:1804.06788](https://arxiv.org/abs/1804.06788).
- **Bayesian workflow and predictive checking:** the bibliography includes Gabry et al. (2019), [doi:10.1111/rssa.12378](https://doi.org/10.1111/rssa.12378).

Use the citation recommended by each upstream repository when it differs from this guide, particularly after a major software release.
